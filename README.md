# Tehreem Fatima — CV & Portfolio

A responsive Next.js portfolio and print-ready CV using the supplied professional details.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Use `npm run build` for a production build and `npm run start` to serve it.

## Save the CV as PDF

Choose **Download CV** in the navigation or hero. In the browser print dialog, select **Save as PDF** and keep the paper size set to A4. The print view is a dedicated text document with selectable content; website sections and controls are hidden.

## Update CV content

Edit the central content in `src/data/cv.ts`. The website and print CV share this data.
